## Назначение программы
Моделирование цифрового двойника технологического процесса по содержанию кислорода в реакторе. Программа последовательно принимает показания X, где  X ∈ (0; 21], преобразует их в Q и контролирует состояние по нижней границе LCL = 35.00.

#### Условие контроля
Тип контроля: нижняя граница (LCL = 35.00).

|Условие|Состояние|
|---|---|
|Q ≥ LCL|НОРМА|
|Q < LCL|ТРЕВОГА|

## Математическая модель и пример расчета
Расчет значений Q осуществлялся по следующей формуле: <br>

$$
Q(X) = \begin{cases}
4\ln(X) + 15, & 0 < X < 2 \\
(X-5)^2 + 45, & 2 \le X \le 8 \\
2(X-8) + 60, & 8 < X \le 21
\end{cases}
$$

при X ∈ (0; 21]. 
ВАЖНОЕ ЗАМЕЧАНИЕ: первое уравнение принимает диапозон 0 < X < 2, так как ln всегда больше 0.
### Пример расчета
$$
\begin{aligned}
&\text{Контрольный пример: } X = 6{,}32 \Rightarrow Q = (6{,}32 - 5)^2 + 45 = 46{,}74 \\
&\text{Пример 1: } X = 1{,}25 \Rightarrow Q = 4\ln(1{,}25) + 15 = 15{,}89 \\
&\text{Пример 2: } X = 4{,}2 \Rightarrow Q = (4{,}2 - 5)^2 + 45 = 45{,}64 \\
&\text{Пример 3: } X = 95 \Rightarrow Q \text{ не определяется, так как } X \notin (0; 21] \\
&\text{Пример 4: } X = 15{,}26 \Rightarrow Q = 2(15{,}26 - 8) + 60 = 74{,}52
\end{aligned}
$$
